# 🎮 PokéShooter: Legendary Catch

Un juego de disparos 2D (Top-down shooter) construido con **Python** y **Pygame**, integrado en tiempo real con **[PokéAPI](https://pokeapi.co/)**.

![Python](https://img.shields.io/badge/Python-3.9+-blue.svg)
![Pygame](https://img.shields.io/badge/Pygame-2.5+-green.svg)
![License](https://img.shields.io/badge/License-MIT-yellow.svg)

---

## 🕹️ Características
- **Consumo dinámico de API:** Descarga los sprites y estadísticas (HP, velocidad) directamente de PokéAPI.
- **Mecánica Shooter:** Apunta con el cursor del mouse y dispara a los Pokémon enemigos.
- **Generación aleatoria:** Enfrenta Pokémon al azar de la primera generación.
